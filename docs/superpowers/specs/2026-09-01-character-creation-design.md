# 角色创建界面设计

## 概述

将角色创建从4步线性向导改为单页表单布局，玩家可以自由切换种族、职业、脸型，实时预览3D角色模型。

## 布局

```
┌──────────┬─────────────────────┬──────────┐
│ 职业信息 │                     │ 职业     │
│ 名称     │                     │ 武士 骑士 │
│ 描述     │    3D 角色预览       │ 机械 魔枪 │
│ 属性     │   (3D场景 + 角色)   │ 弓箭 祭司 │
│          │                     │ 枪兵 法师 │
│          │                     │ 刺客 萨满 │
│          │                     │ 脸型     │
│          │                     │ [0][1][2] │
│          │                     │ 名字     │
│          │                     │ [______] │
│          │                     │ [创建]   │
│          │                     │ [取消]   │
└──────────┴─────────────────────┴──────────┘
```

- 左栏：职业信息（名称、描述、属性）— 纯展示
- 中央：3D 角色预览 + 游戏场景背景 + idle 动画 + 鼠标拖拽360°水平旋转
- 右栏：职业选择 → 脸型选择 → 名字输入 → 创建/取消按钮，全部交互操作集中在右侧（符合右利手习惯）

## 3D 场景

### 场景文件

使用原版角色创建专用场景 `game/maps/chrselect/select.smd`，通过已有的 SMD 解析器加载。

场景纹理（均在 `game/maps/chrselect/` 下）：
- `sky_c.bmp` — 天空
- `cs_ground_line.bmp` / `cs_ground_linetop.bmp` — 地面线
- `cs_01.bmp` — 场景主纹理
- `se_poza.bmp` / `se_poza03.bmp` / `se_roundpoza01.bmp` — 装饰元素
- `doma_body01.bmp` / `doma_face01.tga` — 场景雕塑

### 摄像机

- 初始角度：俯视 90°（从上方看）
- 鼠标拖拽：水平旋转 360°，垂直方向锁定（不上下倾斜）
- 缩放：滚轮可调整摄像机距离

### 光照

使用场景自带的光照信息（SMD 文件内嵌）。

## 交互规则

### 职业选择

- 共10个职业，左列为铁木（Tempscron）右对齐，右列为摩瑞（Moryon）左对齐，中间留空隙
- 职业 ID 对应关系：
  - 铁木: 1=武士, 2=机械, 3=弓箭, 4=枪兵, 5=刺客
  - 摩瑞: 6=骑士, 7=魔枪, 8=祭司, 9=法师, 10=萨满

#### 视觉状态

| 状态 | 名字颜色 | 背景 | 角色预览 |
|------|---------|------|---------|
| 默认 | 普通 | 无 | 显示选中的职业（无选中则为空） |
| Hover | 高亮 | 高亮 | 切换到 hover 的职业（默认脸0） |
| 选中 | 持续高亮 | 持续高亮 | 显示选中的职业 |

#### 交互规则

- 鼠标 hover 某职业 → 名称高亮 + 背景高亮 + 预览切换到该职业（默认脸0）
- 鼠标离开 → 取消 hover 高亮，预览切回当前选中的职业
- 点击选中某职业 → 名称持续高亮 + 背景持续高亮
- 已选中状态下 hover 其他职业 → 仍切换预览，但鼠标离开后回到选中的职业
- 未选中任何职业时，预览区为空（显示场景但无角色）

### 脸型选择

- 3个脸型选项（编号 0、1、2），位于职业选择下方
- 默认选中脸型 0
- 点击选中后，脸型框高亮
- 切换职业时，脸型保持不变（不重置）

### 职业信息（右栏）

- 选中职业后显示：职业名称、描述文字、属性信息
- 未选中职业时显示提示文字（如"请选择职业"）

### 3D 预览

- 进入页面时先加载场景
- 选择职业后加载对应角色模型
- 切换职业或脸型时重新加载模型
- 加载后自动播放 idle 待机动画
- 加载失败时在预览区域显示错误提示，不阻塞创建流程

### 名字输入

- 允许：中文、英文字母、数字
- 长度：2-12 字符
- 正则：`^[\u4e00-\u9fa5a-zA-Z0-9]{2,12}$`
- 名字不合法时"创建"按钮禁用

### 按钮行为

- **取消**：返回角色列表页面
- **创建**：
  1. 发送 `C2S_CreateCharacter { name, class_id }` protobuf
  2. 等待 `S2C_CreateCharacterResult` 响应
  3. 成功：刷新角色列表，显示角色列表页面
  4. 失败：在界面上显示错误原因，停留在创建页面

## 数据流

```
用户操作 → 前端状态更新 → 3D预览更新 / 职业信息更新
                ↓
        点击"创建"
                ↓
    encodeClient(createCharacter) → ws.send()
                ↓
    服务端 handleCreateCharacter()
                ↓
    S2C_CreateCharacterResult → decodeServer → onMessage
                ↓
    成功 → sendCharacterList → 刷新列表
    失败 → 显示错误
```
