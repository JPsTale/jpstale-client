# HUD 重设计方案

> 基于原版PT UI的忠实还原 + 可配置键位系统

## 1. 设计目标

- 忠实还原原版PT HUD的视觉风格和布局
- 按16:9比例（1280×720）调整尺寸和间距
- 新增可配置键位系统

### 2.2 缩放策略

- 画布固定1280×720逻辑像素
- CSS缩放适配视口：`scale = min(viewportW/1280, viewportH/720)`
- 画布居中，两侧/上下留黑边
- DPR感知：canvas实际像素 = 逻辑像素 × DPR

## 4. 时间同步与昼夜系统

### 4.1 时间同步协议

采用混合方案：初始同步 + 本地推进 + 定期校正。

**初始同步（连接时）：**
- 服务端发送 `OpCode::Connected`，附带当前游戏时间（毫秒）
- 客户端接收后转换为游戏分钟：`dwGameWorldTime = dwTime / GAME_WORLDTIME_MIN`
- 存储 `dwConnectedServerTime` 和 `dwConnectedClientTime` 用于后续校正

**本地推进：**
- 客户端按800ms = 1游戏分钟自行推进时间
- `dwGameHour = dwGameWorldTime / 60 % 24`
- `dwGameMin = dwGameWorldTime % 60`

**定期校正（每4秒）：**
- 客户端发送 `OpCode::CheckNetState`，附带 `计算的服务器时间 = (本地时间 - 连接时客户端时间) + 连接时服务端时间`
- 服务端回传当前时间
- 客户端计算漂移，偏差>10分钟时强制校正，否则允许小范围漂移

**相关文件：**
- netplay.cpp:1672-1679（初始同步）
- netplay.cpp:5471-5585（心跳对时）
- OnSever.cpp:19801-19862（服务端响应）

### 4.2 游戏时间系统

| 常量 | 值 | 含义 |
|------|-----|------|
| GAME_WORLDTIME_MIN | 800 | 800ms真实时间 = 1游戏分钟 |
| GAME_HOUR_DAY | 4 | 黎明开始 |
| GAME_HOUR_GLOW | 22 | 日落开始 |
| GAME_HOUR_DARKNESS | 23 | 完全黑暗 |
| GAME_HOUR_NIGHT | 0 | 深夜 |

**昼夜循环：**
```
深夜(0-3) → 黎明(4) → 白天(4-21) → 日落(22) → 黑暗(23) → 深夜(0)
```

### 4.3 客户端渲染

**天空背景切换：**
- 每个场地有3套天空贴图：`BackImageCode[0]`=日，`[1]`=暮，`[2]`=夜
- 按 `dwGameHour` 选择：4-21=日，22=暮，23-3=夜
- 天空切换时平滑交叉淡入淡出（HoSky.cpp:696-753）

**暗度系统（DarkLevel）：**
- `DarkLight` 为天空配置的目标值
- `DarkLevel` 每4帧向目标值插值±1（playmain.cpp:2412-2416）
- 用于动态灯光颜色：`lightRGB * DarkLevel / 256`

**动态灯光：**
- 带 `smLIGHT_TYPE_NIGHT` 标记的灯光仅夜间渲染
- 其他灯光始终渲染，但受 DarkLevel 调色

**日月时钟HUD：**
- 8-18点显示太阳图标，其余显示月亮
- 时条按昼夜进度填充：
  - 白天：`fill = 50 * (hour-4) / 19`（从左到右）
  - 夜晚：`fill = 50 * (hour+1) / 5`（从右到左）

### 4.4 服务端逻辑

- 每1024 tick重新计算昼夜状态（OnSever.cpp:8359-8366）
- 夜间替换NPC为怪物（噩梦事件字段）
- 控制事件怪物刷新（字段代码3，夜间刷 code 100 怪物）
- 村庄内 DarkLevel 减半（character.cpp:6861-6863）
