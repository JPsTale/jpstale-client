# 大地图组件（`src/ui/WorldMap.ts`）

**区域 → 地图**（两级；见 §一·六）。**游戏与调试宿主共用同一份实现**
（`worldmap.html` 只是宿主：URL 带状态 + `?selftest=1` 自检）。

## 一、数据（只有一套）

- **平面图**：`/res/image/planemap/<mapId>.webp`（统一比例尺、像素 (0,0) ↔ AABB 西北角），
  由 `npm run bake-maps` 烘焙 —— 见 `docs/planemap-bake.md`。比例尺与扩展名从同目录
  `index.json` 读（页面**不写死** `.png`）。
- **区域与分组**：`src/maps/planemap-regions.ts`（`CONTINENT_GROUP` 大陆 + `OFFWORLD_GROUPS` 11 个分组，各带依据注释）。
- **等级门**：`src/maps/map-levels.generated.json`（`npm run map-levels`，源自 `gamedb.maplist.levelreq`）。
  **0/1 = 无实质限制**，只有 >1 才在名字后加括号（`mapLabelOf()`）。

## 一·五、形态：FF14 风格窗口（用户 2026-09-15 照 FF14 定稿）

用户是 FF14 玩家，形态逐条对过：**不是全屏页、不是对话框**；窗口可拖（标题栏）、可拉大小（右下角）、几何持久化。

**canvas 左侧一竖条功能按钮** —— 竖条是**绝对定位浮在地图之上**的（不占画布宽度；半透明底，
地图铺满整个窗口）。用户 2026-09-15 指出过"你的按钮不是浮在 canvas 上，而是单独占了一竖条空间"。
（原来那列地图名字**已删掉** —— FF14 没有，靠点击 + "上级"导航）：

| # | 按钮 | 行为 |
|---|---|---|
| 1 | **↑ 上级地图** | 里查顿 → 大陆；亚特兰蒂斯 → 神秘联邦；迷失岛 → 迷失岛；**在副本里无作用**（它不在世界上，按钮置灰） |
| 2 | **◎ 复位到我** | 玩家不在当前显示的那张图上 → **连图一起切过去**（打开的是 A、人在 B → 切到 B，区域也一并换）；已经在同一张图/同一区域 → 只居中、**不改缩放** |
| 3 | **◐ 非激活时半透明** | 鼠标不在窗口里 → 窗口变淡（默认 50%，`ui-prefs.worldMapDimAlpha`）+ **左侧控件与右下角拉伸手柄一起隐藏**（`visibility:hidden`，不用 `display:none`：后者会让画布重排、地图跳一下）；鼠标进窗口即恢复。关掉这个开关则 100% 不透明、控件常驻 |
| 4 | **◆ 图标开关** | 传送门 / 出生点 |
| 5 | **A 文字开关** | 区域名 / 等级门 |
| 6 | **竖排比例尺滑块** | 上下两端分别为 **+ / −**；滑块**顶端 = 最放大**，对数刻度。**范围 8 ~ 128 单位/px**（用户 2026-09-15 定：`ZOOM_MIN/ZOOM_MAX`）。**滑块旁显示当前比例** `N 单位/px`（跟随滑块上下走；悬停有说明：1 像素 = N 世界单位、1 单位 = 1cm、烘图基准 16）。取景（`fitTo`）也会夹进这个范围 —— 否则初始视野落在范围外、读数与滑块位置互相打架 |

- **右下角 = 玩家当前坐标** `(x, z)`；**右上角 = 鼠标指向的世界坐标** `(x, z)`（都忽略 y，地图是平面）。
- 地图区：滚轮缩放（以光标为锚）、拖拽平移；玩家位置 = 红点 + 朝向箭头。
- 偏好（`ui-prefs`，都是部分更新）：`worldMapRect` / `worldMapDim` / `worldMapDimAlpha` / `worldMapPoi` / `worldMapLabels`。

## 一·六、层级：只有**两级** —— 区域 → 地图

> 用户 2026-09-15 连着纠正了我两次：先是"'大陆'不等于世界地图"，然后是我又加了一层"世界"之后：
> **"你为什么一定要搞一个 世界地图→区域→地图 三层？"** —— 对，不该有第三层。顶层就是**你所在的区域**。

| 层 | 内容 |
|---|---|
| **区域**（顶层） | `大陆`(24) / `迷失岛`(2) / `神秘联邦`(8) / 副本家族（非野外，只在身处其中时才存在） |
| **地图** | 单张 |

- **"上级地图"（竖条第 1 项）**：地图 → **它所属的区域**（里查顿 → 大陆；亚特兰蒂斯 → 神秘联邦；
  迷失岛 → 迷失岛）；**区域层已是顶层 → 无作用（置灰）**；**副本 → 无作用（置灰）**（副本不在大陆上）。
- **右键**：地图 → 区域；区域层不再往上。
- **Esc**：地图 → 区域；区域层 → 关闭窗口。
- **M 打开**：`openAtPlayer`（默认 true）→ 一开就是"我在的地方"（副本里 = 那个副本；野外 = 所在那张图），
  再用 `↑`/右键退回它的区域。
- 数据：`CONTINENT_GROUP`（大陆也是一个**区域**）+ `OFFWORLD_GROUPS`（大陆之外的 11 个分组）；
  `ALL_LAYERS` = 两者之和（**12 个区域**），`layerOf(mapId)` 给出"这张图属于哪个区域"。

  青色菱形；**悬停显示"→ 目标地图（等级）"**。

- 图标是**我们自己定的**（原版世界图上没有这些图标），所以界面里写明了"图例是我们定的"。

## 三、组件 API

```ts
const bigMap = createWorldMap(host, {
  assetDir: 'image/planemap',            // 可选，默认就是这个
  getPlayer: () => ({ mapId, x, z }),    // 每帧读一次；画"你在这"（原版世界图上也有这个箭头）
  onPick: (mapId) => {},                 // 点中某张图（浏览下钻之外，游戏侧要的动作）
  browse: true,                          // 点图是否自动下钻；只想"选中"就设 false
  onVisibility: (v) => {},               // 开/关（联动 HUD）
  onLevelChange: (s) => {},              // 层级变化 {level, groupId, mapId}
});
bigMap.toggle(); bigMap.show(); bigMap.hide();
bigMap.goTo({ level: 1, groupId: 'kelvezu' });   // 直接跳层（URL 状态/自检用）
bigMap.getState();                                // { level, groupId, mapId }
bigMap.worldToScreen(x, z) / screenToWorld(sx, sy);
bigMap.focusMap(id); bigMap.redraw(); bigMap.destroy();
```

交互：**左键下钻**（大陆上点哪张进哪张）、**右键 / `Esc` 上升**、滚轮缩放（以光标为锚）、拖拽平移；
左栏是**层级选择器**（大陆只有一项，26/25 张图在世界图上直接点，不在左栏铺开）。

### 层级：由**激活栈**决定（`src/ui/layerStack.ts`）—— **声明即参与**

规则（用户定）：**谁被激活谁在最上**（激活 = 刚打开，或点击它）。

实现（用户 2026-09-16 定的做法）：激活时先给自己一个最大序号，然后**把当前所有层重排成 1..N**
（`A:101 B:102 C:103` → 激活 A 后 `B:101 C:102 A:103`），z-index = `100 + 序号`。

为什么重排而不是"每次 +1、涨到阈值再压缩"：**z-index 永远是最小的连续整数**，
"会不会涨到 9999+/溢出（32 位上限 2147483647）"这个问题**根本不会产生**；
与相邻层（世界 50 / 常驻装饰 1150+）永远留足余量，不需要算概率。重排只重编号、不改先后，
开销 O(层数) 而窗口数是个位数。

**加新窗口不需要改层栈代码，只要在元素上写两个属性**（`MutationObserver` 自动登记/注销）：

```html
<div data-layer="panel:shop">…</div>                     <!-- 一扇窗（独立） -->
<div data-layer="chat" data-layer-host="panels">…</div>   <!-- 归属宿主容器 panels -->
<div id="jp-react-panels" data-layer-host-container="panels">…</div>  <!-- 宿主容器 -->
<div data-layer="worldmap">…</div>                        <!-- 大地图窗口 -->
```

这么改的原因（用户 2026-09-16）："**所有 UI 面板应该都是这同一套逻辑吧？难道每次都要你手动加？**"
—— 之前每加一扇窗都要手写 `registerLayer(...)`，于是漏掉了 NPC 商店、拆分弹框、死亡面板，
而且漏了没有任何提示。现在"参不参与排序、叫什么名字"写在元素自己身上，读代码就能看见。

| 参与排序（有 `data-layer`） | 刻意不参与 |
|---|---|
| 各面板 `panel:*`（背包/角色/技能/NPC 商店，均由 `PanelShell` 一处声明） | 加载页 1400（永远压住一切） |
| 系统菜单 `systemMenu`、聊天窗 `chat` | 开发工具 DevLog/Perf 100000 |
| 大地图 `worldmap` | 常驻装饰：持物图标 1300 / 悬停信息 1350 / 世界内小地图 60 |
| 拆分堆叠弹框 `splitDialog`、死亡三选项 `deathPanel` | |

三条不变量（都是踩坑换来的，详见 `layerStack.ts` 文件头）：
1. **登记"窗口"本身，不是它的全屏包裹层**（地图那次：`.jp-wm` 成了层叠上下文，`win` 永远浮不出来）。
2. **宿主容器的 z-index = 组内当前最高层的值**（空容器退回基准）：容器必须自己有 z-index 才能让整组
   压住世界层，但那又会让它成为层叠上下文 —— 合成值同时满足两件事。
   ⚠ **漏了这条就会"窗口在、位置对、却一个像素看不见"**：`position: fixed` **自身就会创建层叠
   上下文**（CSS Positioned Layout 规范），于是窗口自己的 `z-index:103` 只在容器内有效，容器以
   `z-index:auto` 参与外层，在 `#world-root{z-index:50}` 面前等同 0 ⇒ 被世界画面整个盖住。
   最小复现：容器 `fixed + z:auto` 时子元素 `z:999` 仍被外层 `z:50` 盖住；给容器 `z:100` 后子元素才到最上。
   这个坑**面板容器和地图容器各犯过一次**（用户 2026-09-16 截图实测），别再有第三次。
3. **只写 `z-index`**，不碰 `display`/`pointer-events`。想临时提高优先级用**内联 zIndex 覆盖**，
   别写 `!important`（会把层栈整条链打断）。

## 六、地图上的图标（与小地图同源）

| 画什么 | 资产 | 画法 |
|---|---|---|
| 玩家 | `image/arrow.tga`（32×32） | 与小地图 `DrawMapArrow` **完全同一套约定**：中心对齐、`scale(-1,1)`、`rotate(朝向)` |
| NPC | `image/npc.tga`（8×8 绿点） | 中心对齐 8×8；原版小地图也只画这些（`DrawMapNPC` 遍历 `smCHAR_STATE_NPC`） |

| 队友 | `image/party.tga`（8×8 白点） | **17 格内 = 原色、更远 = 染红**（`character.h: PARTY_GETTING_DIST2 = (17*64)^2`） |

  改 `WorldMap.ts` 的 `MARKER_SRC` / `drawEntities` 一处即可。
- **队友标记原版写了但 exm 里被注释掉了** —— 那是 exm 的删减，不代表原版没有；用户明确要求画，
  规则按 `PARTY_GETTING_DIST2` 实现。**数据源尚未接**：客户端还没消费 `S2C_PartyUpdate`，
  所以 `WorldView.worldMapEntities()` 现在只返回 NPC 与怪物，队友那一路空着（**不伪造数据**）；
  队伍系统落地后往那个函数里塞 `{ kind: 'party', x, z }` 即可，别处不用改。

### 跟随换图（用户 2026-09-15 报的 bug）

**症状**：角色跑到另一张地图后，大地图始终显示上一张。
**原因**：`show()` 里只在"打开那一刻"按玩家位置 `goTo`，之后就不管了 —— 我上轮把"跟随"理解成了
"每次打开都定位"，而用户要的是**玩家换图就跟着切**。
**做法**：`draw()` 每帧末尾调 `syncToPlayer()`（组件约 15fps 重绘，换图自然被看到）：
- 按 **mapId 去重**（不是按坐标）→ 玩家在同一张图里跑动**不会**把视野强行拉回他身边，
  可以一边跑一边看地图别处；只要他不换图就不会被打扰。
- 玩家换图 → `goTo` 到新图（区域也一并切过去，副本 → 所属家族）。
- 手动翻去的图在看，玩家换图了照样跟随（用户要的就是"永远跟着我当前所在地图"）。
- `openAtPlayer: false` 的宿主不受影响（自检/URL 状态控制的实例）。

### 两个坑（都是"静默失败"型）

1. **染色图必须返回 canvas，不能返回 `Image`**（已修）：`Image` 走 `src=` 要**异步解码**，
   解码完成前 `drawImage` 画上去是**空白 —— 不报错、不抛异常**。症状是"染过色的怪物/队友图标
   时隐时现，原色图标正常"；更坏的是调试时随手加一句 `getImageData` 读取就"好了"（同步读取顺带
   把解码推完）—— 那是时序假象，不是修好。`tintUiImage` 现在返回 `HTMLCanvasElement`（同步可画）。
2. **自检读像素前必须先等底图**（`whenImagesReady()`）：底图是 `<img>` 异步加载的，
   `complete` 之前画的是 `#2c3742` 占位色而不是地图。自检里读到占位色就会"凭空失败"，
   而且失败信息看起来像"图标没画"（曾据此白查一轮）。
