## 完成

### HUD（jpstale-web/src/ui/Hud.ts）
- 1280×720 画布，内容按原版 800×600 坐标绘制。
- 定位：水平焦点（HP/MP 与拳头中点，原版 x≈400）对齐画布中心 640，即 `ctx.translate(240,120)`；垂直贴画布底。
- CSS 等比缩放 + 底部锚定（`fitCanvas`）。
- 原版纹理：menu-1/2.tga、bar_life/mana/stamina(填充)、bar_exp、日月、时条、功能按钮、拳头(skill_normal.bmp 49×46 @349,541/403,541)、药水槽底图。
- 结论：bar Shadow*/inter_01..03 无可用内容（纯黑占位）→ 不绘制。

### 服务端对时（PingService + GameClock + transport）
- pong.timestamp = 服务器单调毫秒（nanoTime≈GetTickCount）。
- 换算 800ms/游戏分；漂移 >10 游戏分 snap；连接即首 ping；isSynced 区分锚定/校正。

### 坐标系统一（map-renderer/fore1/WorldView/decor-loader）
- 权威（对齐 jpstale-server loader/RenderMapPng）：smd 分量0=东、分量2=北；GL 目标 东=+X、北=−Z。
- `wx=+A/256, wz=−C/256`；`rawToWorld=(x,y,−z)`；服务端 startPoint 不改。

### 昼夜 + 按图档案（WorldView dnUpdate + map-light.ts）
- MeshBasicMaterial+顶点色 → 光照只能经 shader uniform（uEnvLight/uSceneLight/uTorch）加法注入顶点色；Three 灯光无效。
- DarkLevel/BackColor 每帧 ±1 渐变、火把、场景灯、村庄夜间减半、地牢恒夜档案。

### 小地图（WorldView 内）
- 统一世界窗口 + 遍历已加载图裁剪同绘；箭头恒居中；i18n 文本标题；TAB 开关。
