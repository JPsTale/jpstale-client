# 伤害数字"打击感"设计

> 日期：2026-09-18
> 范围：客户端 `WorldView.ts` 飘字本体（运动方向 / 弹跳缩扩 / 层级差异），`main.ts` 两行传参。
> 状态：已与用户确认（设计草案 → 方向语义纠正 → 批准）。

## 目标

伤害数字从"战斗日志"变成"命中瞬间的**视觉标点**"：命中同步已满足（`S2C_AttackResult` 到达即
`showFloater`，误差 ≪50ms）；本期为数字加入**方向性、形变、层级**三样动态，体现攻击冲击力。

不在本期：音效（既有 `WeaponPlaySound`）、顿帧 / 震屏（`render/wave-camera.ts` 子系统）、
受击闪白 / 击退（怪物动画层）、手柄震动（浏览器端无）。这些由各自子系统承接，不混进数字本身。

## 1. 运动方向（核心新增）

`showFloater` 增加可选 `attackerId` 参数，**仅 `attackResult` 两条**（正常伤害 / MISS）传
`ar.attackerId`；其余（怪打玩家 `S2C_Damage`、治疗 `recovery`）不传。

- 生成时：若攻击者位置与受击者头顶屏幕位置均可解析，则
  `dir = normalize(受击屏幕位置 − 攻击者屏幕位置)`（**屏幕空间**）；否则 `dir = null`。
- 攻击者屏幕位置：`attackerId == self → charGroup` 投影；否则查 `remotes`（防御性，现实中
  `S2C_AttackResult` 恒发给攻击者本人）。
- **有 `dir`**（自机打怪）：数字沿 `dir` 平移 `DRIFT（普通 30 / 暴击 44 px）× easeOut(t)`，
  并叠 24px 上飘，成斜抛——玩家在怪左侧 ⇒ 数字向右冲出（**沿冲击力方向被推出去**）。
- **无 `dir`**（受击 / 治疗 / MISS / Blocked）：保留原垂直 48px 上飘 + 线性淡出。层级分明。

`S2C_Damage`（怪打玩家）**无 `attacker_id`**（`message.proto:686`）——受击方数字不追方向，保持上飘。

## 2. 弹跳 / 缩扩

每个数字生命周期拆两段：

| 段 | 时间 | 行为 |
|---|---|---|
| 弹跳段 | 0→140ms | `scale`：普通 **1.35** / 暴击 **1.8**（ease-out 回落，带 overshoot：冲大 → 略缩 <1 → 回 1） |
| 上飘段 | 140→1000ms | scale 恒 1.0；方向漂移 / 上飘继续，线性淡出（维持原版 1s 节奏） |

纯函数 `bounceScale(now, born, S)`，两段 ease-out 组合，无 NaN。

## 3. 层级差异（暴击金闪）

暴击在弹跳之外叠 `ctx.shadowColor='#ffb84d'; shadowBlur≈px*0.6`（canvas 原生，每帧几条开销可忽略），
与既有 字号×2 + 橙色 + 更大的 DRIFT 一起构成爆发感。颜色表其余不变。

## 4. 信息克制

保留 `floaters ≤ 64` 上限；**不做自动合并**（已确认，等实测刷屏再说）；MISS / 免疫快速淡出维持现状。

## 5. 可调性

参数集中到 `WorldView.ts` 文件头一块常量（`S_NORMAL/S_CRIT`、`BOUNCE_MS`、`DRIFT_NORMAL/DRIFT_CRIT`、
`DRIFT_UP`、overshoot 值），带注释。设置页接入（数字大小 / 关闭 / 减少动态）留待后续，本期不建 UI。

## 6. 回归

- 新增 `npm run verify-dmgfx`：
  - `bounceScale`：单调回落、端点（t=0 >1、末端 ==1）、无 NaN；
  - **漂移方向**：攻击者在受击者左侧 ⇒ `dir.x > 0`（向右飞——钉住用户纠正过的语义）；
  - 确定性：同 id 同刻结果不变。
- `npx tsc --noEmit`；实机打怪确认手感。
